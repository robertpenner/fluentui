## Overview

The Motion Components package provides six **presence components** that handle the most common UI animation needs. Each component manages visibility state and plays appropriate enter/exit animations.

## For Motion Designers

### Available Components

| Component    | Animation              | Best For                                  |
| ------------ | ---------------------- | ----------------------------------------- |
| **Fade**     | Opacity transition     | Tooltips, notifications, overlays, modals |
| **Scale**    | Size grow/shrink       | Popovers, menus, buttons, emphasis        |
| **Collapse** | Height/width expansion | Accordions, expandable sections           |
| **Slide**    | Directional movement   | Drawers, panels, carousels                |
| **Blur**     | Focus/defocus effect   | Background dimming, depth                 |
| **Rotate**   | 3D rotation            | Card flips, reveals, playful interactions |

### Timing Variants

Fade, Scale, and Slide each provide `Snappy` and `Relaxed` variants. Their default enter and exit durations are:

| Component | Default (enter / exit) | Snappy (enter / exit) | Relaxed (enter / exit) |
| --------- | ---------------------- | --------------------- | ---------------------- |
| **Fade**  | 200 / 200 ms           | 150 / 150 ms          | 250 / 250 ms           |
| **Scale** | 250 / 200 ms           | 200 / 150 ms          | 300 / 250 ms           |
| **Slide** | 200 / 200 ms           | 200 / 200 ms          | 250 / 250 ms           |

`SlideSnappy` changes the enter easing to `curveDecelerateMax` and the exit easing to `curveAccelerateMax`, keeping Slide's default durations.

**Collapse** also has a **Delayed** variant that adds a delay before the collapse begins, useful for accordions where you want the content to be readable briefly before collapsing.

### Direction Support

**Slide** can move content in any direction — left, right, up, or down. This makes it versatile for drawers that slide in from the edge of the screen, panels that reveal from a specific side, or page transitions that move content horizontally.

### Choreography with Stagger

**Stagger** coordinates multiple animations in sequence, creating a cascading ripple effect — like items in a list appearing one after another instead of all at once. It's ideal for lists, grids, card layouts, and any group of elements that should animate in sequence.

## For Developers

### Installation

```bash
npm install @fluentui/react-motion-components-preview
# or
yarn add @fluentui/react-motion-components-preview
```

### Basic Usage

```tsx
import { Fade, Scale, Slide, Collapse } from '@fluentui/react-motion-components-preview';

function MyComponent() {
  const [showTooltip, setShowTooltip] = useState(false);

  return (
    <Fade visible={showTooltip}>
      <div className="tooltip">Hello!</div>
    </Fade>
  );
}
```

### The `.In` and `.Out` Pattern

The root component, such as `Scale`, always manages presence: `visible` selects its enter or exit motion. Its `.In` and `.Out` components play one-way motions on mount, without a `visible` prop.

<InOutDemo />

```tsx
import { Fade, Scale, Slide } from '@fluentui/react-motion-components-preview';

// Presence: enter from the left and exit to the right
<Slide visible={isVisible} fromX="-24px" inX="0px" toX="24px">
  <Content />
</Slide>

// One-way enter: opacity 0.2 to 0.7
<Fade.In fromOpacity={0.2} toOpacity={0.7}>
  <Content />
</Fade.In>

// One-way exit: scale 1.2 to 0.8, without a fade
<Scale.Out fromScale={1.2} toScale={0.8} animateOpacity={false}>
  <Content />
</Scale.Out>
```

#### Endpoint Props

For `Fade`, `Scale`, `Slide`, `Rotate`, and `Blur`, `from*` and `to*` always describe the playback source and destination on both `.In` and `.Out`. The present-pose props (`inOpacity`, `inScale`, `inX`, `inY`, `inAngle`, and `inRadius`) belong only to the root presence component. On a root, an omitted `to*` mirrors its corresponding `from*`.

| Component | Presence enter               | Presence exit              | `.In` and `.Out` playback    |
| --------- | ---------------------------- | -------------------------- | ---------------------------- |
| `Fade`    | `fromOpacity` to `inOpacity` | `inOpacity` to `toOpacity` | `fromOpacity` to `toOpacity` |
| `Scale`   | `fromScale` to `inScale`     | `inScale` to `toScale`     | `fromScale` to `toScale`     |
| `Slide`   | `fromX/fromY` to `inX/inY`   | `inX/inY` to `toX/toY`     | `fromX/fromY` to `toX/toY`   |
| `Rotate`  | `fromAngle` to `inAngle`     | `inAngle` to `toAngle`     | `fromAngle` to `toAngle`     |
| `Blur`    | `fromRadius` to `inRadius`   | `inRadius` to `toRadius`   | `fromRadius` to `toRadius`   |

Omitted directional endpoints use the preset's enter or exit defaults:

| Component | `.In` defaults                           | `.Out` defaults                          |
| --------- | ---------------------------------------- | ---------------------------------------- |
| `Fade`    | Opacity 0 to 1                           | Opacity 1 to 0                           |
| `Scale`   | Scale 0.9 to 1                           | Scale 1 to 0.9                           |
| `Slide`   | Translation `(0px, 0px)` to `(0px, 0px)` | Translation `(0px, 0px)` to `(0px, 0px)` |
| `Rotate`  | Rotation -90 to 0 degrees                | Rotation 0 to -90 degrees                |
| `Blur`    | Blur `10px` to `0px`                     | Blur `0px` to `10px`                     |

Slide needs an authored offset to produce translation. If either axis of a source or destination is supplied, its omitted axis is `0px`. For example, `<Slide.Out fromX="4px" toY="-8px">` moves from `(4px, 0px)` to `(0px, -8px)`.

Scale, Slide, Rotate, and Blur include directional fades by default: `.In` fades from 0 to 1, while `.Out` fades from 1 to 0, regardless of the authored pose endpoints. Set `animateOpacity={false}` to animate only scale, translation, rotation, or blur.

#### Timing, Variants, and Replay

For Fade, Scale, Slide, Rotate, and Blur, use `duration`, `easing`, and `delay` to customize a one-way motion, including `.Out`. Explicit `.Out` timing overrides variant defaults. The `exitDuration`, `exitEasing`, and `exitDelay` aliases remain supported on `.Out` and take precedence over their ordinary counterparts when both are supplied.

Snappy, Relaxed, and custom variants retain `.In` and `.Out`. For example:

```tsx
import { ScaleRelaxed } from '@fluentui/react-motion-components-preview';

<ScaleRelaxed.Out fromScale={1.2} toScale={0.8} duration={150}>
  <Content />
</ScaleRelaxed.Out>;
```

One-way motions play once on mount. Change `replayKey` to replay without remounting the child, preserving its DOM and component state:

```tsx
<Slide.In fromX="-24px" replayKey={animationVersion}>
  <Content />
</Slide.In>
```

`replayKey` replays the existing animation; it does not rebuild keyframes from changed motion parameters. Use a new React `key` to remount when a new set of endpoints is needed.

Finishing `.Out` does not unmount the child. Use a root presence component with `unmountOnExit` when visibility should control mounting.

**Use cases for `.In` and `.Out`:**

- Page load animations (use `.In` for entrance-only)
- Exit transitions before navigation (use `.Out`)
- Choreographing different enter/exit from different components
- Looping or staggered animations

### Using Variants

Variants are separate exports with pre-configured timing:

```tsx
import {
  Fade, FadeSnappy, FadeRelaxed,
  Scale, ScaleSnappy, ScaleRelaxed,
  Collapse, CollapseSnappy, CollapseRelaxed, CollapseDelayed,
  Slide, SlideSnappy, SlideRelaxed
} from '@fluentui/react-motion-components-preview';

// Quick feedback for small UI
<ScaleSnappy visible={showMenu}>
  <Menu />
</ScaleSnappy>

// Relaxed feel for important content
<FadeRelaxed visible={showModal}>
  <Modal />
</FadeRelaxed>
```

### Customization with Parameters

All components accept parameters to customize their behavior:

```tsx
// Custom opacity range (e.g. fade to semi-transparent instead of invisible)
<Fade visible={isVisible} fromOpacity={0.5} inOpacity={1}>
  <Content />
</Fade>

// Slide from a specific direction
<Slide visible={isVisible} fromX="100px">
  <Content />
</Slide>

// Horizontal collapse (instead of default vertical)
<Collapse visible={isVisible} orientation="horizontal">
  <Content />
</Collapse>
```

See the Component Reference table below for key parameters.

### Choreography with Stagger

Animate lists of items in sequence:

```tsx
import { Stagger, Fade } from '@fluentui/react-motion-components-preview';

function List({ items, visible }) {
  return (
    <Stagger>
      {items.map(item => (
        <Fade key={item.id} visible={visible}>
          <ListItem>{item.name}</ListItem>
        </Fade>
      ))}
    </Stagger>
  );
}
```
